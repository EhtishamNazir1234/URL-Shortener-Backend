# URL-Shortener-Backend
a backend application that will convert your given url to the shortId. Remember to add "https:/" in the url
#Step 1
clone it into your pc
#Step 2
go to the directory using cd where you have cloned this project
#Step 3
run "npm i"to install all the required dependencies in the package.json
#Step 4
run "npm start"

you're on the go to use the project
after that you can check the routes by exploring the project
